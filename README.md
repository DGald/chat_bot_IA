Chatbot de Soporte Técnico con IA

Un chatbot especializado desarrollado para automatizar las respuestas de soporte técnico utilizando Procesamiento de Lenguaje Natural (NLP) y lógica de Fuzzy Matching (búsqueda difusa).
 Características

  Análisis Multilingüe: Detecta y traduce automáticamente las consultas de los usuarios del inglés al español para encontrar la mejor solución en la base de conocimientos.
  Coincidencia Inteligente: Utiliza algoritmos de similitud de texto para entender la intención del usuario a pesar de errores tipográficos (ej. entiende "vépene" como "VPN").
  Interfaz de Chat en Tiempo Real: Interfaz conversacional moderna y fluida construida con Streamlit.
  Base de Conocimientos Escalable: Arquitectura basada en diccionarios que permite expandir las soluciones de forma rápida y sencilla.

 Tecnologías Utilizadas

  Python 3.x: Lógica central y procesamiento de datos.
  Streamlit: Framework para la interfaz de usuario web.
  Deep Translator: Integración para el soporte multilingüe en tiempo real.
  Difflib: Librería para algoritmos avanzados de comparación de cadenas de texto.
